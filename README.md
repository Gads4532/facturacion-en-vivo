# Facturación en vivo · Fundafarmacia

Página que muestra la facturación de hoy en tiempo real (GitHub Pages). Este repositorio solo tiene el diseño de la
página: no guarda ventas ni claves. Los datos los entrega, en el momento, una app de Google Apps Script que exige la
clave que trae el link del reporte diario (después de `#k=`, que el navegador nunca envía a GitHub).

El código fuente y las instrucciones están en el repositorio `fundafarmacia-proyectos`
(`reporte-de-ventas/tiempo-real/`).
